## Features

✅ **Farmer, Buyer & Transporter Sign In** - Secure access for all stakeholders
✅ **Mobile Money Integration** - Easy payments via MTN & Airtel
✅ **Weather Forecasting** - Plan your farming with accurate weather data
✅ **AI Agricultural Advice** - Expert guidance for maize, beans, cassava, banana, tomato & more
✅ **WhatsApp Support** - Direct support when you need us
✅ **Fair-Trade Marketplace** - Direct connections between farmers and buyers
✅ **Community Stories** - See farmers in action in gardens and at markets

```bash
npm run dev
```
